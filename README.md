# 🚀 Kairox Multichar

Kairox Multichar is an advanced FiveM script that provides a complete multi-character system with identity management and character creation.

Designed for performance, simplicity, and immersion, it is perfect for roleplay servers.

---

## ✨ Features

* Multi-character system
* Full identity creation
* Character creation interface
* Clean and modern UI
* Optimized performance
* Easy to install and configure

---

## 📦 Installation

1. Download the script
2. Place it in your `resources` folder
3. Add this to your `server.cfg`:

   ```
   ensure kairox_multichar
   ```
4. Configure the script to your needs

---

## ⚙️ Configuration

All settings can be configured in the config file included in the script.
